# 八字反推 · 大师级覆盘设计规格

> 目标：让反推达到"往上一回忆，确实有这么回事"的信服度。
> 这是 BKing 的信任钩子、粘性引擎、裂变密码——不是玄学小工具。

## 一、覆盘话术结构（对应真实大师打法）

大师让人信服，靠的不是"方向"，靠的是这些**精准维度**：

| 维度 | 产出 | 记忆钩子 |
|---|---|---|
| 具体年份 | "哪年/几岁时" | 人对年份的记忆锚点 |
| 人物画像 | 小人/贵人/异性伴侣 | 可"对上号"的人物 |
| 身体事件 | "几岁得过什么病" | 身体事件最扎心难忘 |
| 事业遭遇 | 换工作/破财/升迁/官非 | 对应真实职场经历 |
| 婚恋变故 | 分手/成婚/桃花/第三者 | 情感记忆最刻骨 |
| 事件轻重 | 大灾/中挫/小波折 | 不会满盘皆灾，有淡有浓 |

## 二、与现有引擎的差距（重写要点）

现状缺：
1. **年份细化** — 只落到"某10年"，需叠加流年精确到年
2. **事件量化** — 需判轻重大小、次数，不能满盘都是灾
3. **多证据交叉** — 五行+十神+宫位+神煞共同触发才算实锤
4. **宫位归位** — 年(祖上/早运)/月(父母/兄弟)/日(自身/配偶)/时(子女/晚年)
5. **神煞辅助** — 桃花/驿马/华盖/羊刃等，给"细节感"
6. **人物画像** — 把十神翻成"具体什么人遭遇"
7. **措辞画面感** — 读起来像高人在覆盘，不是报表

## 三、事件 → 人物画像映射

| 命理符号 | 翻成生活里的人 |
|---|---|
| 七杀 | 强势对手、上司打压、小人背后中伤 |
| 伤官 | 口舌是非、挑刺的人、年少气盛惹的权威 |
| 劫财/比肩 | 合伙分利的伙伴、同辈竞争者、被借钱不还的人 |
| 偏财 | 投机伙伴、偏门机会里的人、暧昧关系 |
| 正官 | 上司/单位/体制、贵人式领导 |
| 正印/偏印 | 长辈贵人、老师、靠山 |
| 桃花 | 情感对象、追求者、婚外对象 |

## 四、输出形式（最终给用户的覆盘文书）

```
【覆盘 · 命主过往】
四柱 + 日主强弱 + 用神

── 每步大运一"章" ──
【xx岁–xx岁 · XX运】← 大运主旨一句话
  · 【具体年份/几岁】事件标题
    人话描述（画面感）
    （依据：十神+五行+神煞交叉）
    轻重：⚠︎大灾 / ·中挫 / ○小波折

── 一生总述 ──
命主一生经历之线条 + 防什么 + 靠什么

※ 免责说明（传统文化视角，非科学）
```

## 五、信任钩子设计（产品层面）

- 覆盘内容要"**对号入座**"——年份准、人物有画像、事件具体
- 但也要有"**留白**"——不必句句全中，抓住 2-3 个实锤就足够信服
- 结尾给"**你回忆一下是否如此**"的引导，天然促成客户自证 + 分享
- 可加"**转发给熟人试试**"裂变钩子
